# AI Resume Analyzer

An AI-powered Resume Analyzer that compares resumes with job descriptions and provides ATS scoring, skill-gap analysis, and AI-driven recommendations.

## Features

* Resume Upload
* ATS Score Analysis
* Skill Gap Detection
* Job Description Matching
* AI-Based Recommendations
* Resume Insights and Suggestions

## Tech Stack

### Frontend

* React
* Vite
* HTML
* CSS
* JavaScript

### Backend

* FastAPI
* Python
* NLP
* Generative AI APIs

### Backend

```bash

python app.py
```

### Frontend

```bash
npm install
npm run dev
```
